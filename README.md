# 斯坦索姆 · 余烬中的誓言

**公开更新版 · 2026-09-06**

[在线游玩](https://al7755260-jpg.github.io/stratholme-embers/) · [本机试玩](http://127.0.0.1:4177/)（先运行 `启动游戏.cmd`）。

Three.js 斜俯视无尽生存游戏，结合 3D 旧城街区与 90 年代像素风。玩家扮演手持圣锤的圣骑士，在燃烧的街巷、拐角与广场迎战腐尸、不死亡者、缝合憎恶和恐惧魔王。

手机和电脑使用同一个网页，无需安装。需要支持 WebGL 2 的现代浏览器；手机版竖屏直接游玩，也可随屏幕方向自适应，首次加载会下载约 16 MB 资源。点击开始后启用声音。最佳存活纪录保存在当前设备的浏览器中。

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左下摇杆 |
| 圣锤三段连击 | 按住 J / 鼠标左键 | 按住右下圣锤 |
| 旋转视角 | 鼠标右键拖动 | 单指拖动街道 |
| 镜头远近 | 滚轮 | 双指缩放 |
| 镜头归中 | R | 归中按钮 |
| 神圣风暴 / 奉献 | Q / E | 点击对应技能 |
| 圣翼闪避 | 空格 | 点击圣翼 |
| 暂停 | Esc / 暂停按钮 | 暂停按钮 |

触屏操作支持同时移动、攻击和调整镜头。手机默认使用清晰的流畅画质，390×844 视口按 390×844 像素渲染，可在“画面与声音”中切换为精致画质。切到后台会暂停游戏；返回后点击继续。旋转手机不再要求切换到横屏。

## 生存规则

- 满血三格，每次有效受击损失一格，连续受击有短暂无敌间隔。靠近掉落的红色血包恢复一格生命。所有来源的血包掉落频率降为旧版的约 1/10，包括大型怪物和原保底掉落。
- 新局只拥有普通攻击与闪避。打碎南街的风暴圣物、东巷的奉献圣物，分别解锁 Q、E 技能。
- 敌人不断增援，随时间与击杀数增多、变强，领主会反复出现，没有最终波次。
- 正常击杀 120 名亡灵触发两秒像素觉醒动画，战场同时暂停。随后进入五秒天使模式：展开圣翼、燃起圣焰、免疫伤害，攻击秒杀任何敌人。
- 街区中的木箱、木桶、路障等可以破坏，油桶能够连锁爆燃。蓝紫圣印常驻角色脚下。

## 本次更新

- 精致画质增加更细的像素采样、柔和接触阴影、金属受光和街道层次；密集尸潮时自动减少额外采样，手机保留轻量画质。
- 手机版恢复竖屏布局，移除强制横屏提示；技能获得提示收进左上角信息区。
- 保留现有角色与锤子模型，行走改为单手向后下方持锤，手腕跟随握柄，收招平滑回到持锤姿势。
- 破坏场景道具时保留音效、碎片和反馈，移除普通破坏的浮动文字。
- 普攻适配用户下载的 Mixamo Great Sword Combo Slash 动捕，形成斜劈、回身挥击、过顶下砸三段；平时仍然单手垂握。来源及适配说明见 [动作来源](src/motion/CREDITS.md)。
- 尸潮升级改为顶部紧凑信息条中的短暂高亮，不再用中央大框遮挡战斗。
- 受击会更明显地后仰、屈膝、击退并打断敌人攻击；大型怪物仍保留重量差异。
- 天使翅膀改为弧形光羽、错落摆动和向外飘散的金色光屑。
- 时间、尸潮、击杀数和天使进度集中在左上角；圣物导航只保留按键与距离。未获得技能显示小锁，血量和地图缩小，全屏与声音开关收进暂停菜单。

## 本地开发

使用 Node.js 22：

```sh
npm ci
npm run dev
```

打开终端显示的本地地址（默认 `http://127.0.0.1:4177/`）。Windows 也可运行 `启动游戏.cmd`。游戏需要 HTTP 服务，不能直接双击 HTML。

```sh
npm run build
npm run preview
```

`dist/` 是可发布的静态站点。所有模型、纹理、字体、特效和音频均随站点提供，游玩时无需模型生成服务或 API 密钥。

## 发布

`main` 分支更新后，GitHub Actions 自动安装依赖、构建并部署到 GitHub Pages。仓库 Pages 的 Source 使用 **GitHub Actions**。Vite 使用相对资源路径，支持项目子目录部署。
